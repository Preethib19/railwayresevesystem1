RAILRESERVE - EDITABLE SOURCE

1. Extract this folder to a normal location such as Documents\RailReserve_Editable.
2. Open VS Code.
3. Choose File > Open Folder and select the extracted RailReserve_Editable folder.
4. Edit RailwayReservationSystem.java and press Ctrl+S to save.
5. Double-click Run_RailReserve.bat to compile and run (requires JDK installed and available on PATH).
6. Open http://localhost:8080 in your browser.

This package contains the editable .java source, not compiled .class files.
Keep the .java filename as RailwayReservationSystem.java because the public class uses that name.
